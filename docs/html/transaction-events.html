Follow events inside a transaction

A transaction bar shows how long an operation lasts. Hollow dots show when something happened inside it: a router hop, a retirement event, or another named point in time.

From packet lifetime to router hops

Open chi_noc.vtr, add RNF0.tx and HNF0.tx, and zoom into the first burst. Each bar is one single-flit packet. Hover over a dot to see its event name, absolute time with the recording’s unit, and attributes such as router ID and hop index. Clicking a dot selects its containing transaction, just like clicking the bar. Hovering elsewhere on the bar retains the transaction tooltip.

Dots use the canvas background with a foreground outline, so they remain distinct on custom-colored and selected bars. Events at transaction endpoints are included. Events outside the visible time window are omitted, rather than pinned to the viewport edge.

Shared events, local positions

Document

The immutable VTR event details contain timestamps, names and attributes. They follow the existing transaction loading and eviction lifecycle.

Canvas cache

Drawing commands convert timestamps through this tile’s viewport. They retain visible positions and event indices, not copies of names or attributes.

Interaction

The hover tooltip resolves those indices against the document. Selection continues to use the transaction identity.

Markers sharing a rounded canvas pixel are drawn once. Every event index is retained, so hovering still lists the events separately. Nearby markers inside the hover radius also share the tooltip. Zooming rebuilds positions and can separate dots that previously overlapped. This is view state: no marker colors, sizes, or layout are written into VTR or persisted in a workspace.

Scope and validation

This renders VTR point events on transaction bars. It does not render stage intervals or give events independent selection identities. Event times outside their containing transaction are not drawn. Legacy FTR recordings without VTR event details retain their bars. Dense groups can produce long tooltips; zoom in or use transaction details to inspect them.

The CHI canvas and interaction tests cover the visible dots, event hover details and transaction selection. The marker geometry test covers a nonzero time origin, viewport and lifetime clipping, endpoint events, empty event lists and multiple events per pixel. The mixed waveform/transaction snapshot covers event rendering alongside signal waveforms.
