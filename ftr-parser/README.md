# FTR Transaction Parser

FTR Parser written in Rust based on [ftr_parser](https://github.com/christiandattinger/ftr_parser) by Christian Dattinger.
For more information on FTR look at https://github.com/Minres/LWTR4SC

This fork adds performance fixes required by the FTR transaction-**events**
convention, including the breaking API changes they entail — see
[PERFORMANCE.md](PERFORMANCE.md).
